## Назначение

Case Converter — расширение для Visual Studio Code, которое преобразует выделенный текст между разными стилями именования идентификаторов (`snake_case`, `camelCase`, `PascalCase`, `kebab-case`, `UPPER_SNAKE_CASE`, `UPPER`, `lower`), а также определяет текущий стиль выделенного текста.

Плагин не является набором сниппетов: результат каждый раз вычисляется из выделенного текста по правилам разбора границ слов.

## Архитектура VS Code в части подключения расширений

Visual Studio Code построен на Electron и Node.js. Пользовательский интерфейс — это Chromium, а вся логика работы с файлами, редакторами и командами вынесена в отдельный процесс — **Extension Host**.

Расширение (плагин) — это пакет, который содержит:

- файл `package.json` с манифестом (имя, версия, команды, точки активации);
- скомпилированный JavaScript-код;
- ресурсы (иконки, README, лицензию).

При запуске VS Code загружает манифесты всех установленных расширений. Код расширения выполняется только тогда, когда срабатывает **событие активации** (`activationEvents`): например, вызов команды, открытие файла определённого языка или запуск VS Code. До этого расширение не занимает память.

Взаимодействие расширения с редактором идёт через API-модуль `vscode`, который предоставляет:

- доступ к активному редактору (`vscode.window.activeTextEditor`);
- работу с документом (`document.getText`, `document.uri`);
- регистрацию команд (`vscode.commands.registerCommand`);
- редактирование текста (`editor.edit`);
- показ сообщений (`window.showInformationMessage`, `showWarningMessage`);
- добавление элементов в палитру команд через раздел `contributes.commands` в `package.json`.

Наш плагин использует именно этот набор: регистрирует команды в манифесте, при вызове получает выделенный текст, преобразует его и заменяет в документе.

## Архитектура плагина

Плагин разделён на два модуля.

### `src/extension.ts`

Отвечает за интеграцию с VS Code:

- регистрирует все команды в `activate()`;
- для каждой команды получает активный редактор и выделенный фрагмент;
- если редактора нет или выделение пустое — показывает предупреждение;
- передаёт текст в модуль `converter`;
- заменяет выделение результатом через `editor.edit`.

### `src/converter.ts`

Содержит всю прикладную логику и не зависит от API VS Code. Может быть протестирован отдельно.

Функции:

- `splitWords(text)` — разбивает исходную строку на массив слов-токенов;
- `isAcronym(word)` — проверяет, является ли слово акронимом (две и более заглавных букв подряд);
- `toUpper`, `toLower`, `toSnake`, `toUpperSnake`, `toKebab`, `toCamel`, `toPascal` — преобразователи массива токенов в строку нужного стиля;
- `CONVERTERS` — таблица соответствия «тип стиля → функция-преобразователь»;
- `convert(text, type)` — точка входа преобразования;
- `detectCase(text)` — определяет стиль строки по набору регулярных выражений.
