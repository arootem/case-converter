# Case Converter

Плагин для Visual Studio Code, который преобразует выделенный текст между разными стилями именования: `snake_case`, `camelCase`, `PascalCase`, `kebab-case`, `UPPER_SNAKE_CASE` и другими. Также умеет определять, в каком стиле написан выделенный текст.

## Возможности

- Преобразование выделенного текста в:
  - `UPPER` — всё заглавными
  - `lower` — всё строчными
  - `snake_case` — слова через подчёркивание, строчными
  - `UPPER_SNAKE_CASE` — слова через подчёркивание, заглавными
  - `kebab-case` — слова через дефис
  - `camelCase` — первое слово строчное, остальные с заглавной
  - `PascalCase` — каждое слово с заглавной
- Определение текущего стиля выделенного текста.
- Корректная обработка акронимов: `parseHTTPResponse` → `parse_HTTP_response`, а не `parse_h_t_t_p_response`.
- Корректная обработка цифр: `user2Name` → `user_2_name`.

## Использование

1. Выделите текст в редакторе.
2. Нажмите `Ctrl+Shift+P` (или `Cmd+Shift+P` на Mac), чтобы открыть палитру команд.
3. Введите `Case:` и выберите нужное преобразование, например `Case: snake_case`.
4. Выделенный текст заменится результатом.

Чтобы узнать текущий стиль выделения, выберите команду `Case: определить регистр`.

## Установка

1. Скачайте файл `.vsix` из раздела Releases.
2. В VS Code откройте панель расширений (`Ctrl+Shift+X`).
3. Нажмите `···` в правом верхнем углу → «Install from VSIX...» → выберите файл.
